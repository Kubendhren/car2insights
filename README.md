Project Overview

Car2Insights is an e-commerce analytics project designed to analyze sales performance, customer behavior, seller performance, product trends, delivery operations, and customer experience using data analytics and visualization.

The project uses the Brazilian E-Commerce Public Dataset by Olist to transform raw e-commerce data into meaningful business insights that support data-driven decision-making.

Project Objectives

Analyze overall business and sales performance.

Understand customer purchasing behavior and retention.

Evaluate seller and product performance.

Monitor delivery performance and order fulfillment.

Analyze customer reviews and satisfaction.

Build interactive dashboards for business reporting.

Integrate MySQL for structured data storage and analysis.
